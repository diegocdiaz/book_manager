# Book Manager

## Sprint actual: Sprint 1

## Objetivo
Aplicar los conocimientos de Programación Orientada a Objetos y persistencia de
datos en archivos, desarrollando un sistema de gestión de inventario para una
librería.

## Introducción y contexto
Una librería con venta al público necesita modernizar su sistema de gestión de
inventario de libros. Debido a la fluctuación en los costos de importación de
material bibliográfico, el sistema debe gestionar precios en diferentes
monedas (ARS, USD) y seguir de cerca la cotización del dólar (Oficial, Blue,
MEP, etc.) para actualizar sus valores en tiempo real. Se desarrolla una
aplicación de consola (CLI) en Python que permite gestionar el inventario,
cotizar los libros según el valor del dólar y comparar precios con la
competencia.
